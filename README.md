<h3 id="descripcion-del-proyecto">Descripción del proyecto:</h3>
Este proyecto se realizo en el marco del curso ONE (Oracle Next Educacation) de las empresas Oracle y Alura Latam, en el cual fue solicitado crear un foro mediante APIRest.

<h3 id="estado-del-proyecto">Estado del proyecto:</h3> 
El proyecto se encuentra en desarrollo, porque es su primer version, aun quedan muchas cosas por crear e ir añadiendo, estoy seguro que debe tener muchas cosas por corregir o mejorar.
Que con el paso del tiempo, las formaciones y practicas ire adquieriendo conocimientos para mejorarlo.

<h3 id="acceso-al-proyecto">Acceso al proyecto:</h3>
Este proyecto es de acceso público.
